# studybuddy-in-java
it is a simple study timer made using JavaFX, it can track time and provide pomodoro sessions for productivity and a study notes manager ,
its minimalistic for clean study sessions! HOW DO I USEIT?? just copy-paste this link in your browser : 

https://alexiscodes.github.io/studybuddy-in-java/?
it currently only runs on web version, i might try to make it an app if i get time 😭 this was honestly tough 

it has features like 
counting 25Min pomodoro timers which can be paused/resumed,started and reset.
my fav is definitely the to do list called 'my study tasks' to keep all the work organised and we also have study notes where u can choose the subject and add some short notes , id personally use this as a student
